<objective>
Add a `db.verboseMarkers` boolean (default `true`) that flips the four marker macros between verbose tokens (`{diamond}`, `{triangle}`, `{circle}`, `{cross}`) and fallback `{rt#}` payloads. A new "Use verbose markers" checkbox in the Macros section of the config panel binds to it, rebuilding the four macros in place on every toggle change via the existing combat-deferral path.

Purpose: Verbose tokens render correctly in more chat addons than the older `{rt#}` codes; default-ON gives every existing and new user the better-rendering tokens automatically; the toggle is the safety valve for users on chat-addon stacks that don't expand verbose names (and the only sane fallback for non-English-locale clients per RESEARCH Q7).
