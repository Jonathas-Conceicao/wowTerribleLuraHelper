## Milestone Scope

Two quality-of-life improvements on top of the shipped v1.0.0 foundation:

1. **Verbose-marker toggle** — let users switch the four marker macros between `{rt#}` (universal) and `{diamond}`/`{triangle}`/`{circle}`/`{cross}` (English-client-only verbose tokens), with a new config-panel checkbox. Default OFF — `{rt#}` is the safe universal default.
2. **Zone-aware auto show/hide** — auto-open the helper window on entering the March of Quel'danas raid, auto-close on leaving. Works across all 5 difficulties (LFR / Story / Normal / Heroic / Mythic). No more remembering `/lura show` before every pull.

## Sequencing Rationale (recorded for posterity)

Phase 7 first because every piece had a battle-tested v1.0.0 analog (macro-channel dropdown for the Settings checkbox + `regenFrame` for combat-lockdown deferral + macro-payload construction in `Macros.lua`). Phase 8 second because it introduced a new event surface (`ZONE_CHANGED_NEW_AREA`) and required identifying the correct Midnight-era M-of-Q raid instanceID — a research surface that turned out to need a live in-game capture (the two-track placeholder approach).

## Research-Driven Refinements (post-context, pre-shipping)

- **Phase 7 RESEARCH Q7 (Localization):** `{diamond}` only renders on English-locale WoW clients (`ICON_TAG_LIST` keys go through locale-loaded global strings); `{rt#}` is universal. Surfaced during research; initially shaped the tooltip wording (D-06 refinement), then promoted to a default-flip during UAT (AMEND-07-01-UAT-01).
- **Phase 8 RESEARCH Q3 (Architecture):** Pivoted from CONTEXT D-08's original `C_Map.GetBestMapForUnit("player")` proposal to `GetInstanceInfo()` instanceID (`select(8, ...)`). Reason: instanceID is shared across all raid difficulties (single scalar covers LFR / Story / Normal / Heroic / Mythic), while uiMapID can split per sub-area. Adopted in the plan and validated by UAT.
- **Phase 8 RESEARCH Q1 (Unknown instanceID):** The actual M of Q raid instanceID wasn't pinned from documented sources. Mitigated via two-track placeholder approach — shipped with sentinel `LURA_RAID_INSTANCE_ID = 0` (safe no-op) + `DEBUG_ZONE_INFO` gated debug-print block. UAT captured `inst=2913` from a live LFR zone-in; `fix(08-01) 3e5ed46` patched the constant and flipped the debug flag back off.

## Late-UAT Amendment (AMEND-07-01-UAT-01)

During the combined Phase 7+8 UAT session on 2026-05-16, after Block A (Phase 7 8 checkpoints) and Block B (instanceID capture) passed cleanly, the user revised the verbose-marker toggle's default:

- Default flipped `true` → `false`. Rationale: `{diamond}` etc. only render on English-locale clients. Any raid group with even one non-English-client player would see broken markers if verbose were the default. `{rt#}` is universal across all locales.
- Tooltip rewritten to lead with the localization warning instead of the modern-chat-addon framing.
- Semantic reframe: toggle is now opt-in for English-only groups (or English-only-but-rt-rendering-is-broken groups), not the default behavior.

Commit `a0c2778 feat(07): flip verbose-markers default OFF + rewrite tooltip (post-UAT)`. Gates re-run, install.bat re-deployed, behavior re-verified in-game before milestone close.
