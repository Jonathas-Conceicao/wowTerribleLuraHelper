## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-typed slash arg → Lua dispatcher | The user types arbitrary text after `/lura`. Treated as untrusted input — must be parsed safely, never eval'd. |
| Slash dispatcher → ns.* state machine | The dispatcher only calls a fixed set of `ns.*` functions; no dynamic dispatch by user input. |
| ns:Disable → multi-step state mutation | Three `ns.*` calls (UnregisterChatEvents, WipeSequence, HideWindow) — all idempotent and safe to call out of order. |
