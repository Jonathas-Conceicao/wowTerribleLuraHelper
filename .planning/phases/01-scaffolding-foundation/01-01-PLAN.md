```markdown
# TerribleLuraHelper

A standalone World of Warcraft Midnight addon that helps a raid coordinate during the Midnight Falls boss fight against L'ura. L'ura displays five runes that the raid must read in order to position correctly; this addon lets one spotter press five pre-bound macros (created by the addon) and surfaces the result, in human-readable form, both in raid chat and in a dedicated helper window every player can see — surviving the boss-fight chat-messaging-lockdown that blocks normal addon chat output.

## Install

Install via CurseForge, Wago, or GitHub Releases once published. For local development, clone the repo and run `./scripts/install.bat` (Windows) to copy the addon into your retail WoW AddOns folder, then `/reload` in-game.

## Slash Commands

- `/lura` — toggle the addon between enabled and disabled
- `/lura show` — enable processing and show the helper window
- `/lura hide` — disable processing entirely (ignores chat events even during combat)
- `/lura clear` — clear the helper window's slot display
- `/lura config` — open the TerribleLuraHelper panel under Options > AddOns
- `/tlh` — alias for `/lura` (all subcommands work the same)

## License

WTFPL v2. See `LICENSE`.
```
